# Nginx 3つの作成パターン（独立資料）

nginx conf は **3本を独立して**作る（方式設計書・Confluence の3対象と一致）。
各パターンは下記の独立資料で「仕組み・必要な設定・必要なファイル・図」が完結する。

| # | パターン | 資料 | テンプレート | njs | loader/DB | S3中継 |
|---|---------|------|------------|-----|-----------|--------|
| 1 | 電文受付① 通常API | [パターン1_電文受付API.md](パターン1_電文受付API.md) | `templates/01-denbun-api.conf.template` | ◯ | ◯ | ✕ |
| 2 | 電文受付② ファイルDL | [パターン2_ファイルDL.md](パターン2_ファイルDL.md) | `templates/02-filedl.conf.template` | ✕ | ✕ | ◯ |
| 3 | 本部画面用 React | [パターン3_React静的.md](パターン3_React静的.md) | `templates/03-react.conf.template` | ✕ | ✕ | ◯ |

## 3パターンの違い（要点）

```
          ┌───────────────┬───────────────────┬───────────────────┐
          │ 1 電文受付API   │ 2 ファイルDL       │ 3 React静的        │
├─────────┼───────────────┼───────────────────┼───────────────────┤
│ 目的     │ API電文の受付   │ 配信ファイルDL     │ 画面(SPA)配信      │
│ 中核機能  │ njsカナリア     │ S3中継(署名付URL)  │ 静的配信+UL/DL中継 │
│ 振分け    │ BODY店舗コード  │ なし               │ なし               │
│ S3       │ 使わない        │ 中継(VPC GW EP)    │ バック+中継         │
│ 認証     │ -              │ -                 │ ALB(OIDC)、nginx不要│
│ 404時    │ 404固定JSON     │ S3エラー素通し      │ index.html(200)    │
│ 構成部品  │ nginx+njs+loader│ nginx単体          │ nginx単体          │
│ 複雑さ   │ 高              │ 低                │ 中                 │
└─────────┴───────────────┴───────────────────┴───────────────────┘
```
